اتصال به سرور API

نشانی سرور عمداً از پیش به سرویس قدیمی متصل نشده است. نشانی بک‌اندی را وارد کنید که نسخهٔ قرارداد canonical آن تأیید شده باشد. این صفحه نشانی یا توکن را در حافظهٔ دائمی ذخیره نمی‌کند.

ابتدا نشانی API را وارد و اعمال کنید.

ورود سفیر

ورود از API واقعی انجام می‌شود. نقش کاربر از پاسخ سرور خوانده می‌شود؛ هیچ انتخاب یا شبیه‌سازی نقش در رابط وجود ندارد.

۱. هاب‌های نزدیک

موقعیت دستگاه فقط پس از فشردن دکمه و اجازهٔ شما دریافت می‌شود. فقط هاب‌هایی که مختصات واقعی دارند نمایش داده می‌شوند.

۲. ثبت مرسوله

ثبت مرسوله فقط با شناسهٔ رضایت صادرشده از پنل مشتری ممکن است. برای تحویل ناموفق، ابتدا تلاش را ثبت کنید و شناسهٔ آن را به گیرنده بدهید تا پس از تأیید OTP صریحاً رضایت دهد.
